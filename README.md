# Clipbus

> The programmable clipboard manager for macOS and Windows.

Clipbus is a keyboard-first clipboard manager you can extend with Node.js plugins — write detectors that react to what you copy (JWT, Base64, JSON, color hex…), render rich inline cards, and run actions on any item, all without leaving the keyboard. Built on a native C++17 core — no Electron, no subscription.

**This repository hosts the official Clipbus release artifacts for macOS and Windows**, their update feeds, and the release notes for the plugin SDK. For the product itself, see **[clipbus.com](https://clipbus.com)**.

## Download

### macOS

- **Direct download (DMG):** [Clipbus.dmg](https://github.com/scubers/clipbus-release/releases/latest/download/Clipbus.dmg)
- **Homebrew:** `brew install scubers/tap/clipbus`

Requires **macOS 14+** (Apple Silicon).

### Windows

- **Installer (EXE):** [clipbus.com/download/windows](https://clipbus.com/download/windows) — always serves the current installer
- **Versioned installers:** attached to the `windows-v*` releases on the [Releases](https://github.com/scubers/clipbus-release/releases) page

Requires **Windows 11 24H2+** (x64).

## About this repository

- **Releases** — macOS releases (`v*`) attach `Clipbus.dmg`, the versioned DMG and `.zip`, and localized release notes. Windows releases (`windows-v*`) attach the installer, `SHA256SUMS.txt`, a release manifest and localized release notes. Plugin SDK releases (`sdk-v*`) carry release notes only; the package itself is published to npm.
- **Latest release** — always the newest macOS build, which keeps the DMG link above stable. Windows and SDK releases are never marked as Latest.
- **Auto-update** — macOS updates itself via [Sparkle](https://sparkle-project.org/) from the appcast on the `gh-pages` branch; Windows checks the signed feed on the `windows-updates` branch. Only `gh-pages` and `windows-updates` are generated by the release pipelines — everything on `main` is hand-maintained.
